# Writing Style and Narrative and Tone

- **Student perspective:** Write naturally as a second-year university student.
- **Grounded in theory:** Connect the content to relevant lecture concepts which can be ref in [lecture slides name]
- **Natural undergraduate writing:** Use simple vocabulary, straightforward grammar, and reasonably not too long sentences. Minor grammatical imperfections are acceptable. Avoid overly polished or sophisticated language.
- **Clear and cohesive:** Keep ideas logically connected and easy to follow. Avoid repetition, generic statements.

## Conventions
- Keep the reports edits in the main Markdown file. Treat the supplied lecture slides [lecture slides name] as reference knowledge material
- Support factual claims with identifiable sources. For lecture references, include the exact page number. Keep in-text citations consistent with the reference list.
- Place all code and scripts used for the report in the `codes/` folder.
