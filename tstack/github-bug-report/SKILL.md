# GitHub bug reports
- use github cli
- To include an image when creating a GitHub issue, run `gh issue create --title "Issue title" --body "Issue description" --attach "path/to/image.png"`

## Gather input

Use the context already available. Ask the user for missing essentials about the target repository or the bug.

## Check the repository

When accessible, follow the project's template and contribution guidelines. Search for duplicates and link any matches.

## Draft the issue

Return a title and Markdown body or the project's issue form fields. Cover reproduction steps, expected and actual behavior, and relevant environment details. Include images if user gives them. Redact sensitive data. Publish only on explicit request.
