# GitHub feature requests
- use github cli
- To include an image when creating a GitHub issue, run `gh issue create --title "Issue title" --body "Issue description" --attach "path/to/image.png"`

## Gather input

Use the context already available. Ask the user for missing essentials about the target repository, their use case, or the behavior they want.

## Check the repository

When accessible, follow the project's template and contribution guidelines. Check issues and discussions for similar proposals and link any matches. Note if the project prefers requests in Discussions.

## Draft the issue

Return a title and Markdown body or the project's issue form fields. Explain the problem and proposed behavior. Include an example, images, or alternatives when helpful. Publish only on explicit request.
