# Set up a coding project

## 1. Review the project

Read the README and any project brief for the purpose, current state, and requirements. Skim the repo layout, configuration, and scripts as needed to identify key directories and documented development commands.

## 2. Fill in the template

Use the [coding setup template](TEMPLATE.md) beside this `SKILL.md` as the base for `AGENTS.md`.

- Keep the template's headings, section order, and default wording.
- Fill in the project name, purpose, and current state. List key directories with repo-relative paths and their roles.
- Under `Codebase Practice`, record project-specific rules and relevant setup, build, and test commands supported by the repo. Remove any placeholder that does not apply.

## 3. Write `AGENTS.md`

Create or update `AGENTS.md` at the repo root.

### When updating an existing file

- Reorganize the file to match the template's layout.
- Preserve existing project instructions unless they conflict with explicit project requirements.
- Keep existing project preferences over template defaults.
- Ask about unresolved conflicts.
