# Set up an assignment-writing project

## 1. Review the assignment

Read the brief and rubric for the assignment goal and requirements. Skim other repo resources only as needed to identify their purpose and location.

## 2. Apply the writing guide

Read the [shared writing setup guide](setup-writting.md) beside this `SKILL.md`. Use its general guidance and add the specialized sections that fit the assignment. Ask about the assignment type only if the answer would change the instructions.

## 3. Write `AGENTS.md`

Create or update `AGENTS.md` at the repo root. Summarize the assignment goal and list relevant resources with their purposes and repo-relative paths.

### When updating an existing file

- Preserve existing project instructions unless they conflict with explicit assignment requirements.
- Keep existing project preferences over template defaults.
- Ask about unresolved conflicts.
